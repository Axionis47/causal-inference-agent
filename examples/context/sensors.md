# Sensor comparison (synthetic acceptance fixture)
Each row records one device during a bench session. unit is its identifier.
signal_a and signal_b are readings from two probes of the same device, in millivolts, recorded together at the close of the session. Both use -999 for an unreadable signal.
temperature records ambient degrees Celsius at the same session.
During recalibration, the operator adjusts signal_a and signal_b together using temperature and a reference standard outside this file. The account describes a joint procedure, not a formula for either reading.
The calibration note says ambient temperature has no direct effect on the reference standard; possible indirect pathways were not assessed.
The reference standard is the certified voltage source used during the bench session. Its certified value is not supplied.
No timing or meaning is supplied for other operations.
