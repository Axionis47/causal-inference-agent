# Memory and endpoint readiness

The durable memory holds one field per addressed column or claim property. Each field retains its value, status, source, source sentence, reason and evidence. `ops.apply` is the write gate. Models draft; only human statements or applicable data checks confirm. Uncheckable causal beliefs require the person's account. Statistical associations do not become confirmed causal relationships.

The family-by-claim matrix still records routing fit, the address that set a cell and its memory version. Within each surviving family, endpoint admission records show required, satisfied, assumed, missing, failed and inapplicable obligations. Requirements come from `endpoints.yaml`, and family decisions are derived from those same declarations. There is no independently maintained interview checklist.

The desk selects the family before completing its required context. It collects relevant confirmations together and asks only unresolved activated endpoint obligations. Optional IV, mediation, modifier, prefix and local-randomisation configurations activate from their relevant account or question. A pending discriminating fact opens a question. An explicit unknown can count as a conditional assumption only when that endpoint permits it. A model-sourced claim cannot make context ready.

Context admission identifies dataset and memory versions, carries source/status statements and endpoint admissions, and is hashed over the complete handoff. The person's run word authorizes that snapshot. The lane verifies identity and re-evaluates admission. The lane's evidence ledger is separate from memory: it preserves source-linked proposals and every revision. Source-backed relationship assertions can return to memory as drafts for review; absent graph arrows do not imply negative facts, and confirmed human claims are not overwritten.

Corrections update memory through the same gate. They invalidate the ready moment and require a new context snapshot and authorization before another run. Data transformations produce a new dataset version rather than modifying the table in place. Analysis journals record actions and evidence; they do not write knowledge.
