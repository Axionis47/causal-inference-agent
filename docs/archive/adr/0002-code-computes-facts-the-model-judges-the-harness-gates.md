# 2. Code computes facts; the model judges; the harness gates

Deterministic code computes every fact: the profile, the probes, the checks, the fit grid, the numbers. A judgement is
one gated model call on rendered material that carries addresses, and the harness refuses an answer that cites an
address the material does not hold or picks a name outside the list, then re-prompts with the rejection.

No code is patched for a dataset. What a dataset needs is in its memory; what a family needs is in its `family.yaml`;
what a lane assumes about beliefs is in its `beliefs.yaml`. The harness reads those as data.
