# 3. A person's word is evidence, never an automatic write

What the person says goes through the same gate as a model's reading: `memory.ops.apply` accepts a field only with a
source, and a belief only on the person's word. A statement is recorded as said, with its turn; whether it settles a
field is decided by the gated judgement that reads it. A contradiction between the file and the words is a status,
shown, never silently resolved either way.
