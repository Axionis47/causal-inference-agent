# The matrix and the journal of one interview

The memory snapshot, the matrix record and the journal of one interview on the Students Performance file, driven by the scripted
`DeskFake` the test suite uses. The matrix and the fit steps are computed by the same code the desk runs; the sentences that fed
them were scripted, not spoken. `make docfigs` reads `matrix.json` and `journal.jsonl` to draw the matrix before and after the
belief answers. Replace all three with a real conversation's records when the demo is re-recorded.
